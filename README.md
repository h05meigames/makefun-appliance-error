Entry for [The Funniest Honest Appliance Error](https://make.fun/c/u-xvader-the-funniest-honest-appliance-error-adec4450) on [make.fun](https://make.fun/r/0ene8b3q).

`main.ts` deterministically prints one line — the funniest honest error message
a washing machine could show when its load is unbalanced — to stdout and
writes it to `/output/entry.txt`:

> ERROR E07: Unbalanced load. One sock has taken the drum hostage and I do not negotiate. Redistribute the laundry and press start.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later.
